# ⌨️ Endless Typing

> **Just type. There is no end.**

**Endless Typing** is a minimal web application built around one simple idea: **keep typing endlessly**.

There are no levels, no timers, no complicated features, and no final destination. Open the website, place your cursor in the typing area, and start typing.

## ✨ Features

* ♾️ **Endless typing** — Keep typing for as long as you want.
* 📝 **Simple typing interface** — No unnecessary distractions.
* 🎯 **Focus on typing** — Just you and the keyboard.
* ⚡ **Lightweight & fast** — Designed to be simple and responsive.
* 📱 **Responsive design** — Works across desktop, tablet, and mobile devices.

## 🎮 How It Works

It's extremely simple:

```text
Open Endless Typing
       ↓
   Start typing
       ↓
    Keep typing
       ↓
       ♾️
```

There is no finish line.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/your-username/endless-typing.git
```

Navigate into the project:

```bash
cd endless-typing
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.

## 🎯 Project Goal

The goal of **Endless Typing** is not to build a complex application.

It's an experiment in **simplicity**.

One page.
One purpose.
One endless stream of typing.

## 🌐 Use Cases

Endless Typing can be used for:

* Practicing typing
* Free writing
* Brain dumping
* Testing keyboards
* Writing random thoughts
* Relaxed typing sessions
* Simply typing for no particular reason

## 📌 Philosophy

> **Don't count the words. Don't chase a score. Just type.**

Endless Typing removes the usual goals and limitations found in typing applications.

There is no:

* ❌ Word limit
* ❌ Time limit
* ❌ Level system
* ❌ Final score
* ❌ Finish button

There is only:

**⌨️ Type.**
